Cara Mengkustomisasi Favicon di Wix

Wix memungkinkan Anda menghapus ikon default pada paket premium. Kustomisasi favicon Anda untuk meningkatkan konsistensi desain toko.

Mengubah Favicon Wix Anda

Catatan: Wix memerlukan paket hosting Premium untuk mengunggah favicon kustom.

  1. Masuk ke Dasbor Situs Wix Anda.
  2. Klik Pengaturan di menu sidebar sebelah kiri.
  3. Klik Pengaturan Situs Web di bawah Pengaturan Umum.
  4. Temukan bagian favicon, dan klik Perbarui Gambar (atau Unggah Gambar).
  5. Pilih gambar PNG Anda dan klik Terapkan.
