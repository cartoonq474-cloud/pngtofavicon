Apa yang Termasuk dalam Unduhan Anda

Semua file yang Anda butuhkan untuk dukungan favicon lintas browser dan lintas perangkat sepenuhnya

ICO

favicon.ico

Format ICO multi-ukuran klasik, berisi ikon 16×16, 32×32, dan 48×48. Diperlukan untuk dukungan browser lama termasuk versi Internet Explorer yang lebih lama.

16

favicon-16x16.png

Ikon tab browser standar dengan ukuran 16×16 piksel. Digunakan oleh sebagian besar browser modern sebagai favicon tab utama untuk tampilan dengan kepadatan standar.

32

favicon-32x32.png

Ikon tab browser beresolusi tinggi (High-DPI) dengan ukuran 32×32 piksel. Ditampilkan pada layar Retina dan HiDPI untuk rendering favicon yang jernih dan tajam di tab browser.

180

apple-touch-icon.png

Ikon Apple Touch berukuran 180x180 piksel untuk iPhone, iPad, dan iPod Touch. Ditampilkan saat pengguna menambahkan situs web Anda ke layar beranda iOS mereka.

192

android-chrome-192x192.png

Ikon layar beranda Android berukuran 192x192 piksel. Digunakan saat pengguna Android menambahkan situs Anda ke layar beranda mereka melalui Chrome atau browser lain.

512

android-chrome-512x512.png

Ikon PWA beresolusi tinggi berukuran 512x512 piksel. Diperlukan untuk prompt instalasi Progressive Web App dan layar pembuka pada perangkat Android.

JSON

site.webmanifest

File Manifest Aplikasi Web yang berisi referensi ikon, warna tema, dan warna latar belakang. Penting untuk dukungan PWA dan integrasi layar beranda Android.

Pertanyaan yang Sering Diajukan

Mengapa menggunakan favikon emoji?
Favikon emoji menyenangkan, deskriptif, dan langsung dikenali. Emoji sangat bagus untuk alat pengembang, blog pribadi, proyek SaaS, dan aplikasi web ringan. Karena emoji sangat terstandarisasi, tampilannya konsisten di berbagai layar.

Apakah alat ini berfungsi dengan emoji sistem khusus?
Ya! Anda dapat mengetik atau menempelkan emoji tunggal langsung ke kolom "Emoji yang Dipilih", dan kanvas rendering kami akan langsung menggambarnya.

Bisakah saya membuat latar belakang menjadi transparan?
Ya. Centang kotak "Tetap transparan (Hanya ikon)", dan alat ini akan merender emoji langsung pada kanvas transparan, menyimpannya sebagai file PNG transparan.

Apakah ikon-ikon ini gratis untuk penggunaan komersial?
Emoji sistem asli yang dirender pada kanvas adalah font sistem standar, yang aman untuk penggunaan web pribadi dan komersial.
