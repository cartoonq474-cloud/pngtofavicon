Apa yang Termasuk dalam Unduhan Anda

Setiap file yang Anda butuhkan untuk dukungan favicon lintas browser dan lintas perangkat penuh

ICO

favicon.ico

Format ICO multi-ukuran klasik, berisi 16×16, 32×32, dan Ikon 48x48. Diperlukan untuk dukungan browser lama termasuk versi Internet Explorer yang lebih lama.

16

favicon-16x16.png

Ikon tab browser standar berukuran 16x16 piksel. Digunakan oleh sebagian besar browser modern sebagai favicon tab utama untuk tampilan dengan kepadatan standar.

32

favicon-32x32.png

Ikon tab browser beresolusi tinggi (High-DPI) berukuran 32x32 piksel. Ditampilkan pada layar Retina dan HiDPI untuk rendering favicon yang jernih dan tajam di tab browser.

180

apple-touch-icon.png

Ikon Apple Touch berukuran 180x180 piksel untuk iPhone, iPad, dan iPod Touch. Ditampilkan saat pengguna menambahkan situs web Anda ke layar beranda iOS mereka.

192

android-chrome-192x192.png

Ikon layar beranda Android berukuran 192x192 piksel. Digunakan saat pengguna Android menambahkan situs Anda ke layar beranda mereka melalui Chrome atau browser lain.

512

android-chrome-512x512.png

Ikon PWA beresolusi tinggi 512×512 piksel. Diperlukan untuk prompt instalasi Progressive Web App dan layar pembuka pada perangkat Android.

JSON

site.webmanifest

File Manifest Aplikasi Web yang berisi referensi ikon, warna tema, dan warna latar belakang. Penting untuk dukungan PWA dan integrasi layar beranda Android.

Pertanyaan yang Sering Diajukan

Mengapa pemeriksa favicon menyatakan bahwa ikon saya hilang, padahal saya bisa melihatnya?
Browser sering kali menyimpan favicon dalam cache secara intensif, jadi Anda mungkin melihat ikon lama yang tersimpan dalam cache meskipun file tersebut hilang dari server Anda, atau jika kode HTML memiliki kesalahan markup. Pemeriksa kami meminta HTML langsung dan menguraikannya kembali untuk melewati cache browser lokal.

Bagaimana cara memperbaiki apple-touch-icon yang hilang?
Buat gambar PNG 180x180, unggah ke root server Anda sebagai apple-touch-icon.png, dan tambahkan <link rel="apple-touch-icon" href="/apple-touch-icon.png"> di dalam header HTML Anda. Anda dapat menggunakan konverter PNG di halaman beranda kami untuk membuat file ini secara otomatis.

Apakah favicon yang hilang memengaruhi SEO mesin pencari?
Ya. Google Penelusuran menampilkan favicon situs web di samping hasil pencarian di tampilan seluler dan desktop. Jika bot Google tidak dapat mengambil favicon Anda, bot akan menampilkan ikon cadangan generik, yang dapat menurunkan rasio klik-tayang (CTR) Anda secara signifikan.
