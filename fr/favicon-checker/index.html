Contenu du téléchargement :

Tous les fichiers nécessaires pour une compatibilité favicon optimale avec tous les navigateurs et appareils

ICO

favicon.ico

Le format ICO classique multi-tailles, comprenant les formats 16×16, 32×32 et 464. Icônes 48×48. Nécessaires pour la compatibilité avec les anciens navigateurs, notamment les anciennes versions d'Internet Explorer.

16

favicon-16x16.png

Icône d'onglet standard du navigateur (16×16 pixels). Utilisée par la plupart des navigateurs modernes comme favicon principal pour les écrans à densité de pixels standard.

32

favicon-32x32.png

Icône d'onglet haute résolution (32×32 pixels). Affichée sur les écrans Retina et haute résolution pour un rendu net et précis des favicons dans les onglets du navigateur.

180

apple-touch-icon.png

Icône tactile Apple (180×180 pixels) pour iPhone, iPad et iPod Touch. Affichée lorsque les utilisateurs ajoutent votre site web à leur écran d'accueil iOS.

192

android-chrome-192x192.png

Icône d'écran d'accueil Android (192×192 pixels). Utilisé lorsque les utilisateurs Android ajoutent votre site à leur écran d'accueil via Chrome ou d'autres navigateurs.

512

android-chrome-512x512.png

Icône PWA haute résolution (512 × 512 pixels). Requise pour les invites d'installation et les écrans de démarrage des applications web progressives sur les appareils Android.

JSON

site.webmanifest

Fichier manifeste de l'application web contenant les références des icônes, la couleur du thème et la couleur d'arrière-plan. Indispensable pour la prise en charge des PWA et l'intégration à l'écran d'accueil Android.

Foire aux questions

Pourquoi le vérificateur de favicons indique-t-il que mon icône est manquante alors que je la vois ?
Les navigateurs mettent souvent en cache les favicons de manière intensive. Il est donc possible que vous voyiez une ancienne icône en cache même si le fichier est absent de votre serveur ou si le code HTML contient des erreurs de balisage. Notre outil de vérification récupère le code HTML en temps réel et l'analyse à jour pour contourner le cache local du navigateur.

Comment puis-je corriger une icône tactile Apple manquante ?
Générez une image PNG de 180 × 180 pixels, téléchargez-la à la racine de votre serveur sous le nom apple-touch-icon.png et ajoutez <link rel='apple-touch-icon' href='/apple-touch-icon.png'> dans l'en-tête de votre code HTML. Vous pouvez utiliser notre convertisseur PNG pour page d'accueil afin de générer ce fichier automatiquement.

Une favicon manquante affecte-t-elle le référencement (SEO) sur les moteurs de recherche ?
Oui. La recherche Google affiche les favicons des sites web à côté des résultats de recherche sur les appareils mobiles et les ordinateurs. Si le robot de Google ne parvient pas à récupérer votre favicon, il affiche une icône générique par défaut, ce qui peut réduire considérablement votre taux de clics (CTR).
