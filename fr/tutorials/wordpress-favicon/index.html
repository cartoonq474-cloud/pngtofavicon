Comment ajouter une favicon à WordPress

WordPress alimente plus de 40 % du Web. Suivez ce guide moderne de 2026 pour vous assurer que votre favicon WordPress s'affiche correctement dans les onglets du navigateur et les écrans d'accueil des mobiles.

L'ajout d'un favicon à WordPress est géré via la fonctionnalité d'icône de site intégrée à WordPress. Vous n'avez normalement pas besoin de créer un fichier favicon.ico, de modifier vos fichiers de thème ou d'installer un plugin favicon. Dans WordPress, le favicon est appelé icône de site. Vous pouvez en ajouter un à partir des paramètres généraux sur WordPress 6.5 et versions ultérieures. Les anciennes versions de WordPress utilisent le Customizer, tandis que les thèmes de bloc peuvent également gérer l'icône via le bloc Logo du site.

Avant de commencer, préparez une image carrée d'au moins 512 × 512 pixels. WordPress recommande le format PNG pour l'icône du site.

Qu'est-ce qu'une favicon WordPress ?

Un favicon est la petite image associée à un site Web. Les navigateurs peuvent l'afficher à côté du titre de la page dans les onglets du navigateur, les signets, la barre d'adresse, l'historique du navigateur et d'autres interfaces du navigateur. Il peut également être utilisé comme icône d’application sur certains appareils. WordPress appelle cette image une icône de site.

L'icône du site et le logo du site ne sont pas nécessairement la même chose :

  • Icône du site : La petite icône utilisée pour identifier votre site Web dans les interfaces du navigateur et autres emplacements pris en charge.
  • Logo du site : L'image de marque plus grande affichée dans le cadre de la conception de votre site Web, comme dans l'en-tête.

Vous pouvez utiliser la même image pour les deux, mais ce n’est pas obligatoire. WordPress prend spécifiquement en charge l'utilisation d'une image de logo de site comme icône de site dans les thèmes de bloc.

Que devez-vous préparer avant d’ajouter une favicon à WordPress ?

Préparez l'image avant d'ouvrir vos paramètres WordPress.

  • Utilisez une image carrée : WordPress exige que l'image de l'icône du site soit carrée et mesure au moins 512 × 512 pixels. Un canevas carré a également du sens visuellement, car les navigateurs affichent les favicons sous forme de petites icônes carrées.
  • Utilisez PNG lorsque cela est possible : WordPress recommande le format PNG pour l'icône du site. PNG fonctionne particulièrement bien pour les logos, les symboles, les initiales et les graphiques qui nécessitent des bords nets ou de la transparence.
  • Gardez le design simple : Une favicon est affichée en très petite taille. Un logo détaillé peut paraître beau à 500 pixels mais devenir illisible lorsqu'il est réduit à une icône de navigateur. Évitez les textes longs, les petits caractères, les lignes fines, les illustrations compliquées et trop d’éléments visuels. Un simple symbole, une initiale ou une marque reconnaissable fonctionne généralement mieux.
  • Utilisez un contraste fort : Assurez-vous que l'élément principal de l'icône reste visible sur son arrière-plan. Par exemple, un texte sombre sur un fond sombre peut devenir difficile à reconnaître lorsque l'icône est réduite.
  • Commencez avec une image de haute qualité : N'agrandissez pas une très petite image et attendez-vous à ce qu'elle produise un favicon net. Commencez avec des illustrations épurées, puis préparez la version carrée dont vous avez besoin pour WordPress.
  • Ne présumez pas que le logo de votre site est automatiquement le meilleur favicon : Un logo d'entreprise complet peut bien fonctionner dans l'en-tête d'un site Web, mais mal comme favicon. Par exemple, un logo horizontal contenant un symbole et un long nom d'entreprise peut devenir illisible une fois réduit. Dans ce cas, utilisez plutôt le symbole ou un court monogramme.

Comment ajouter une favicon sur WordPress ?

Pour WordPress 6.5 et versions ultérieures, WordPress a déplacé le paramètre Icône du site vers Paramètres généraux. Il s’agit de la principale méthode à utiliser sur les installations WordPress actuelles.

  1. Connectez-vous à votre tableau de bord WordPress : Ouvrez votre zone d'administration WordPress et connectez-vous. Vous avez besoin d'un accès de niveau administrateur ou d'autorisations suffisantes pour modifier les paramètres du site.
  2. Ouvrez les paramètres généraux : Depuis le tableau de bord WordPress, ouvrez Paramètres ��� Général.
  3. Recherchez le paramètre Icône du site : Recherchez la section Icône du site. Vous devriez voir une option intitulée Choisissez une icône de site.
  4. Téléchargez ou sélectionnez votre favicon : Cliquez Choisissez une icône de site. WordPress vous permettra de sélectionner une image dans votre médiathèque ou de télécharger l'image préparée. Choisissez votre image favicon carrée (au moins 512 × 512 pixels, PNG recommandé).
  5. Confirmez l'image : Après avoir sélectionné l'image, vérifiez attentivement l'aperçu. Assurez-vous que la bonne image est sélectionnée, que la partie importante de votre conception est visible, que l'icône n'est pas inutilement compliquée et que l'image est carrée. Si l'image contient un logo avec un très petit texte, pensez à préparer une version simplifiée avant de l'utiliser comme icône du site.
  6. Enregistrer l'icône du site : Enregistrez les modifications des paramètres généraux. L'icône du site est désormais associée à votre site WordPress.
  7. Ouvrez le site Web en direct : Ouvrez votre site Web dans un nouvel onglet de navigateur. Vérifiez l'icône à côté du titre de la page. Ne jugez pas le résultat uniquement à partir de l’écran d’administration de WordPress. Le véritable test est le site Web publié dans un navigateur.

Où est le paramètre Favicon dans WordPress ?

L'emplacement dépend principalement de votre version de WordPress et de la configuration du thème.

Où se trouve le paramètre Favicon dans WordPress 6.5 et versions ultérieures ?

Pour WordPress 6.5 et versions ultérieures, utilisez :

Administrateur WordPress → Paramètres → Général → Icône du site

WordPress a déplacé l'icône du site du personnalisateur vers les paramètres généraux dans WordPress 6.5. Il s’agit de l’itinéraire standard actuel.

Où était le paramètre Favicon dans les anciennes versions de WordPress ?

Dans les versions 4.3 à 6.4 de WordPress, l'icône du site était gérée via le personnalisateur :

Administrateur WordPress → Apparence → Personnaliser → Identité du site → Icône du site

Vous avez ensuite sélectionné ou téléchargé une image carrée d'au moins 512 × 512 pixels. Cela explique pourquoi les anciens didacticiels WordPress peuvent afficher un chemin de navigation différent. Si votre tableau de bord ne correspond pas à ces instructions, vérifiez d'abord votre version de WordPress avant de supposer que la fonctionnalité a disparu.

Où est le paramètre Favicon dans un thème de bloc ?

Les thèmes de blocs fournissent un autre flux de travail via l'éditeur de site. Le bloc Logo du site comprend un Utiliser comme icône du site choix. Lorsqu'elle est activée, l'image attribuée au bloc Logo du site est également utilisée comme icône du site. Ceci est particulièrement pertinent lorsque vous travaillez avec un thème de bloc moderne et que vous passez la plupart de votre temps dans Apparence → Éditeur.

Comment ajouter un Favicon avec un thème de bloc WordPress ?

Un thème de bloc peut gérer l'icône du site via le bloc Logo du site.

  1. Ouvrir l'apparence → Éditeur : Depuis votre tableau de bord WordPress, accédez à Apparence → Éditeur. Cela ouvre l'éditeur de site WordPress pour un thème de bloc.
  2. Recherchez ou ajoutez le bloc Logo du site : Votre thème comporte peut-être déjà un bloc Logo du site dans son en-tête. Sélectionnez-le. S’il n’en existe pas, ajoutez un bloc Logo du site via l’outil d’insertion de blocs. La documentation de WordPress explique que le bloc peut être inséré dans des modèles dans l'éditeur de site.
  3. Ajoutez votre image : Sélectionnez le bloc Logo du site et téléchargez une image ou choisissez-en une dans la médiathèque.
  4. Ouvrez les paramètres du bloc : Avec le bloc Logo du site sélectionné, ouvrez la barre latérale des paramètres. Cherchez le Utiliser comme icône du site choix.
  5. Activez « Utiliser comme icône du site » : Allumer Utiliser comme icône du site. WordPress utilisera cette image comme icône du site.
  6. Enregistrez vos modifications : Enregistrez les modifications dans l'éditeur de site, puis ouvrez le site Web en direct et vérifiez l'onglet du navigateur.

Le logo du site et l'icône du site peuvent également être différents. WordPress documente un flux de travail de logo de site dans lequel le logo peut être utilisé pour définir initialement l'icône, puis une autre icône de site peut être sélectionnée par la suite.

Comment créer un Favicon pour WordPress ?

Vous disposez de plusieurs façons de créer l’image avant de la télécharger.

Comment créer un Favicon à partir de votre logo ?

Commencez par le logo de votre marque existant. Si le logo est déjà un simple symbole carré, il vous suffira peut-être de le redimensionner et de l’exporter. Si le logo est horizontal, simplifiez-le d’abord. Supprimez le texte inutile ou utilisez la partie la plus reconnaissable du logo. Ne traduisez pas le logo et ne modifiez pas le nom de la marque dans le cadre du processus de création de favicon. Préserver l’identité originale de la marque tout en adaptant l’œuvre à un petit format carré.

Comment créer un Favicon à partir d'initiales ou de texte ?

Un favicon peut utiliser une ou deux lettres au lieu d’un logo complet. Par exemple, une société appelée North Star Digital pourrait utiliser N.-É. plutôt que d'essayer d'insérer le nom complet dans l'icône. Utilisez des caractères gros et lisibles avec suffisamment de contraste.

Comment convertir un PNG en Favicon ?

Si vous disposez déjà d'une image PNG, vous pouvez utiliser un outil de conversion de favicon pour préparer une version de favicon. Par exemple, PNGversFavicon.com peut convertir un PNG existant en illustration favicon. Ceci est utile lorsque vous disposez déjà d’un logo ou d’une icône appropriée mais que vous devez préparer une version de favicon avant de la télécharger sur WordPress. Après la conversion, vérifiez l'image résultante en petite taille avant de l'utiliser comme icône de votre site.

L’exigence importante de WordPress est toujours la même : l’image doit être carrée et faire au moins 512 × 512 pixels.

Quelle doit être la taille d’un favicon WordPress ?

WordPress nécessite qu'une icône de site soit carrée, d'au moins 512 × 512 pixels, et recommande le format PNG. Ce sont les exigences documentées actuelles de WordPress.

Ne confondez pas la taille de l'image que vous téléchargez avec la taille à laquelle le navigateur affiche finalement le favicon. Un navigateur peut afficher l'icône dans une taille beaucoup plus petite que l'image originale téléchargée. C’est pourquoi il est important de commencer avec une image suffisamment grande et propre.

Comment vérifier si votre favicon WordPress fonctionne ?

Après avoir enregistré l'icône du site, consultez le site Web en direct.

  • Vérifiez l'onglet du navigateur : Ouvrez votre site Web et regardez l'onglet du navigateur. L'icône du site doit apparaître à côté du titre de la page. C'est le moyen le plus simple de confirmer que le favicon est diffusé par votre site Web.
  • Vérifiez un favori : Ajoutez le site Web à vos favoris et vérifiez si l'icône apparaît à côté du signet. Les favicons peuvent également être utilisés dans l'historique du navigateur et dans d'autres interfaces du navigateur.
  • Testez le site dans une fenêtre privée ou incognito : Si votre ancien favicon est toujours visible, ouvrez le site Web dans une fenêtre privée ou incognito. Cela vous donne un test plus propre, car votre session de navigateur normale peut toujours avoir le favicon précédent en cache.
  • Testez un autre navigateur : Ouvrez le site Web dans un deuxième navigateur. Si le nouveau favicon apparaît ici mais pas dans votre navigateur principal, le paramètre WordPress est peut-être déjà correct et le problème restant peut être la mise en cache du navigateur.
  • Vérifiez le domaine actif : Assurez-vous que vous visitez le bon domaine publié. Ne testez pas accidentellement un site Web intermédiaire, une installation de développement, un ancien domaine ou une autre installation WordPress.

Pourquoi mon favicon WordPress ne s'affiche-t-il pas ?

Une favicon manquante ne signifie pas automatiquement que le téléchargement de l'icône du site a échoué. Plusieurs problèmes différents peuvent provoquer le même résultat.

Cache du navigateur

Problème: Votre navigateur continue d'afficher l'icône précédente.
Réparer: Ouvrez le site Web dans une fenêtre privée ou incognito. Si la nouvelle icône apparaît ici, l'icône du site fonctionne probablement. Vous pouvez également vider le cache du navigateur et redémarrer le navigateur.

L'icône du site n'a pas été enregistrée

Problème: Vous avez sélectionné l'image mais n'avez pas enregistré le paramètre.
Réparer: Revenez aux paramètres de l'icône du site, confirmez que la bonne image est sélectionnée et enregistrez les modifications.

Vous consultez le mauvais site Web

Problème: Le favicon n’a pas changé car vous avez modifié une installation ou un domaine WordPress différent.
Réparer: Confirmez le domaine que vous modifiez et le domaine que vous testez.

L'image ne répond pas aux exigences de WordPress

Problème: L'image n'est pas carrée ou mesure moins de 512 × 512 pixels.
Réparer: Préparez une image carrée avec des dimensions d'au moins 512 × 512 pixels. PNG est le format recommandé.

La favicon a été modifiée récemment

Problème: WordPress a la nouvelle icône du site, mais le navigateur affiche toujours la version précédente.
Réparer: Testez dans un autre navigateur ou dans une fenêtre privée avant de modifier à nouveau l'icône du site.

Votre thème de bloc utilise le workflow Logo du site

Problème: Vous vous attendiez à trouver un paramètre d'icône de site traditionnel, mais votre thème utilise principalement le bloc Logo du site.
Réparer: Accédez à Apparence → Éditeur, sélectionnez le bloc Logo du site et cochez Utiliser comme icône du site.

Un plugin de mise en cache sert une ancienne version

Problème: Votre site WordPress utilise un plugin de mise en cache qui n'a pas encore régénéré sa sortie en cache.
Réparer: Videz le cache du plugin de mise en cache, puis testez à nouveau le site Web. (Cela s'applique uniquement lorsqu'un système de mise en cache est réellement utilisé.)

Un CDN ou un cache serveur est impliqué

Problème: Le navigateur continue de recevoir une ancienne version des actifs du site.
Réparer: Purgez le CDN ou le cache du serveur concerné si votre configuration d'hébergement en utilise un, puis testez à nouveau dans une fenêtre privée.

Comment vider le cache de WordPress ou du navigateur après avoir modifié une favicon ?

La mise en cache ne doit être vérifiée qu'après avoir confirmé que l'icône du site a bien été enregistrée. Utilisez cette séquence :

  1. Confirmez que l'icône du site est correcte dans WordPress.
  2. Enregistrez la modification.
  3. Videz le cache de votre plugin de mise en cache WordPress, s'il est installé.
  4. Videz votre cache CDN si votre site Web utilise un CDN.
  5. Ouvrez le site Web dans une fenêtre privée ou incognito.
  6. Testez le site Web dans un autre navigateur.
  7. Vérifiez le favicon dans l'onglet du navigateur.

Cela sépare le problème de configuration de WordPress du problème de mise en cache. Ne remplacez pas le favicon à plusieurs reprises simplement parce que votre navigateur continue d'afficher l'image précédente.

Comment modifier ou remplacer un favicon WordPress ?

Remplacer une icône de site est similaire à en ajouter une.

Pour WordPress 6.5 et versions ultérieures

  • Connectez-vous à WordPress.
  • Accédez à Paramètres → Général.
  • Rechercher l'icône du site.
  • Choisissez une autre image dans la médiathèque ou téléchargez-la.
  • Confirmez l'image.
  • Enregistrez les paramètres.
  • Ouvrez le site Web en direct et vérifiez l'onglet du navigateur.

La documentation actuelle de WordPress place l'icône du site dans les paramètres généraux pour WordPress 6.5 et versions ultérieures.

Pour les anciennes versions de WordPress

Sur WordPress 4.3 à 6.4, utilisez Apparence → Personnaliser → Identité du site → Icône du site, puis sélectionnez l'image de remplacement et enregistrez vos modifications.

Comment supprimer un favicon WordPress ?

Le processus de suppression dépend de si vous utilisez les paramètres généraux, le personnalisateur ou un thème de bloc.

Supprimer l'icône du site de WordPress actuel

Ouvrez les contrôles de l'icône du site sous Paramètres ��� Général et utilisez le contrôle de suppression ou de remplacement disponible fourni par votre installation WordPress. Étant donné que les interfaces WordPress peuvent varier selon les versions et les thèmes, ne vous fiez pas à un nom de bouton spécifique provenant d'un ancien didacticiel.

Supprimez l'icône du site du personnalisateur

Les anciennes installations WordPress gèrent l'icône via Apparence → Personnaliser → Identité du site. Le panneau Identité du site contient le contrôle Icône du site et permet de modifier ou de supprimer l'image.

Supprimer l'icône du site d'un thème de bloc

Les thèmes de bloc peuvent utiliser le bloc Logo du site pour contrôler l'icône du site. Ouvert Apparence → Éditeur, sélectionnez le bloc Logo du site et vérifiez ses paramètres d'image et d'icône du site. Supprimer l'image du bloc Logo du site et supprimer l'icône du site ne sont pas nécessairement la même opération, alors vérifiez le paramètre Icône du site lui-même lorsque votre objectif est spécifiquement de supprimer le favicon.

Pouvez-vous ajouter une favicon WordPress avec du code ?

Oui, mais le codage est généralement inutile. WordPress dispose d'une fonctionnalité d'icône de site intégrée, de sorte que les sites Web normaux doivent utiliser le paramètre intégré plut��t que d'ajouter manuellement un balisage favicon aux fichiers de thème. WordPress propose la fonctionnalité Site Icon depuis la version 4.3.

Quand devriez-vous utiliser l’icône de site intégrée à WordPress ?

Utilisez l'option intégrée lorsqu'elle est disponible. Il est plus simple, plus facile à maintenir et évite les modifications inutiles des fichiers de thème.

Quand un code personnalisé peut-il être nécessaire ?

Le code personnalisé peut avoir du sens pour un thème personnalisé ou une implémentation spécialisée dans laquelle les contrôles intégrés ne fournissent pas le comportement requis. Avant de modifier le code du thème, déterminez si le thème existant prend déjà en charge la fonctionnalité Icône du site. N'ajoutez pas une deuxième implémentation de favicon simplement parce que vous ne pouvez pas trouver imm��diatement le paramètre.

Avez-vous besoin d’un plugin pour ajouter un Favicon à WordPress ?

Non. Un plugin favicon dédié n’est normalement pas nécessaire. WordPress dispose d'une fonctionnalité intégrée d'icône de site et la documentation officielle recommande de l'utiliser plutôt que de créer et d'installer manuellement une implémentation favicon.ico distincte. Un plugin peut être pertinent pour une exigence spécialisée, mais en installer un simplement pour ajouter une icône de site standard ajoute une dépendance inutile.

Erreurs courantes de favicon WordPress à éviter

  • Utiliser une image non carrée : WordPress exige que l'icône du site soit carrée.
  • Téléchargement d'une image inférieure à 512 × 512 pixels : Préparez l'icône aux dimensions minimales requises plutôt que de commencer avec une petite image source.
  • Utiliser un logo compliqué : Un logo détaillé peut devenir impossible à reconnaître lorsqu'il est réduit à la taille d'un favicon.
  • Rendre le texte trop petit : Les noms d’entreprises et les slogans longs deviennent généralement illisibles.
  • Utilisation d'un mauvais contraste : Une favicon à faible contraste peut disparaître sur l'interface d'un navigateur.
  • Commencer avec une source de mauvaise qualité : Une image floue ou fortement compressée ne produira pas un résultat net.
  • Oublier de sauvegarder : La sélection d'une image n'aide pas si le paramètre n'est pas enregistré.
  • Vérification d'un seul navigateur : Utilisez une fenêtre privée ou un autre navigateur lors de la vérification d'un favicon récemment modifié.
  • Confondre le logo du site avec l'icône du site : Ils servent à des fins différentes. Le logo de votre site apparaît dans la conception du site Web, tandis que l'icône du site est utilisée comme petite icône de navigateur et d'application.
  • Modification du code inutilement : Utilisez la fonctionnalité intégrée d'icône de site de WordPress avant de modifier les fichiers de thème.
  • En supposant que le favicon a échoué parce que l'ancienne icône reste visible : La mise en cache du navigateur peut faire apparaître une modification réussie comme un échec.

FAQ sur les favicons WordPress

Comment s’appelle un Favicon dans WordPress ?

WordPress appelle le favicon une icône de site. Il identifie votre site Web dans les onglets du navigateur, les signets et autres emplacements pris en charge.

Quelle doit être la taille d’un favicon WordPress ?

L'icône du site doit être une image carrée d'au moins 512 × 512 pixels. WordPress recommande PNG comme format.

Puis-je utiliser un PNG comme favicon WordPress ?

Oui. PNG est le format recommandé par WordPress pour les icônes de site.

Puis-je utiliser mon logo comme favicon WordPress ?

Oui. Un logo peut être utilisé comme icône de site, mais il doit rester reconnaissable lorsqu'il est réduit à une très petite taille. Un logo horizontal complexe devra peut-être être simplifié en un symbole, un monogramme ou un autre élément de marque reconnaissable.

Pourquoi mon favicon WordPress ne s’affiche-t-il pas ?

Vérifiez d’abord que l’icône du site a été enregistrée et que vous testez le bon site Web en direct. Ouvrez ensuite le site dans une fenêtre privée ou dans un autre navigateur pour exclure la mise en cache des favicon. Si vous utilisez un plugin de mise en cache ou un CDN, purgez également son cache.

Comment changer mon favicon dans WordPress ?

Sur WordPress 6.5 et versions ultérieures, accédez à Paramètres → Général → Icône du site, choisissez la nouvelle image et enregistrez les modifications. Les anciennes versions de WordPress utilisent Apparence → Personnaliser → Identité du site → Icône du site.

Comment supprimer une favicon WordPress ?

Ouvrez les contrôles Site Icon utilisés par votre version WordPress et supprimez ou remplacez l'image sélectionnée à l'aide du contrôle disponible. Les anciennes versions le gèrent via Apparence → Personnaliser → Identité du site, tandis que les thèmes de bloc peuvent exposer les contrôles de l'icône du site via le bloc Logo du site.

Ai-je besoin d’un plugin pour ajouter une favicon dans WordPress ?

Non. WordPress dispose d’une fonctionnalité d’icône de site intégrée, donc un plugin n’est normalement pas requis.

Où est le paramètre d’icône du site dans WordPress 6.5 ?

Accédez à Paramètres → Général → Icône du site. WordPress a déplacé l'icône du site vers les paramètres généraux dans la version 6.5.

Où se trouve le paramètre d’icône du site dans les anciennes versions de WordPress ?

Pour WordPress 4.3 à 6.4, utilisez Apparence → Personnaliser → Identité du site → Icône du site.

Puis-je utiliser la même image pour mon logo et mon Favicon ?

Oui, mais vous n’êtes pas obligé. Un logo de site complet peut contenir des détails qui ne fonctionnent pas bien à la taille d'une favicon. Dans les thèmes de bloc, WordPress permet également d'utiliser l'image du logo du site comme icône du site via Utiliser comme icône du site.

Combien de temps faut-il pour mettre à jour une favicon WordPress ?

Il n’existe pas d’heure d’affichage universelle fiable car les navigateurs peuvent mettre en cache les données des favicon. Après avoir enregistré l'icône du site, testez le site en direct dans une fenêtre de navigateur privée ou dans un autre navigateur. Effacez également les caches de WordPress, du CDN ou du serveur, le cas échéant.

Comment créer un Favicon avant de le télécharger sur WordPress

Utilisez ce flux de travail lorsque vous ne disposez pas déjà d’une icône de site appropriée :

  1. Commencez par votre logo, symbole ou initiales existant. Gardez le logo original et l’identité de la marque intacts.
  2. Simplifiez l’illustration pour qu’elle reste reconnaissable lorsqu’elle est affichée très petite.
  3. Créez une toile carrée.
  4. Faites en sorte que l'image fasse au moins 512 × 512 pixels.
  5. Exportez-le au format PNG.
  6. Vérifiez l'icône sur les petites tailles d'affichage.
  7. Convertissez un PNG existant en illustration favicon si nécessaire.
  8. Téléchargez l'image terminée sur WordPress en tant qu'icône du site.

Conclusion

Pour ajouter un favicon à WordPress, préparez une image carrée d'au moins 512 × 512 pixels, puis ouvrez Paramètres → Général → Icône du site sur WordPress 6.5 et versions ultérieures. Sélectionnez ou téléchargez l'image, enregistrez les paramètres et consultez le site Web en direct dans un navigateur. Les anciennes installations WordPress utilisent Apparence → Personnaliser → Identité du site, tandis que les thèmes de bloc peuvent également gérer l'icône via le bloc Logo du site. Si le nouveau favicon n'apparaît pas immédiatement, vérifiez la mise en cache du navigateur, de WordPress, du CDN ou du serveur avant de supposer que le téléchargement a échoué.
