Comment personnaliser Favicon sur Wix

Wix vous permet de supprimer les icônes par défaut sur les forfaits premium. Personnalisez votre favicon pour améliorer la cohérence de la conception du magasin.

Un favicon est la petite icône qui représente votre site Web Wix dans les onglets du navigateur, les favoris et autres interfaces du navigateur. Wix fournit un paramètre de favicon intégré, vous n'avez donc normalement pas besoin de modifier le code de votre site.

Pour les sites Wix standard, vous avez besoin d'un forfait Premium et d'un domaine connecté pour ajouter une favicon personnalisée, et Wix exige que le site soit publié avant d'en ajouter un. Le flux de travail Wix actuel utilise les paramètres du site Web, tandis que le nouvel éditeur Wix Harmony fournit également une option Ajouter un favicon directement à partir de son panneau Présentation du site.

Ce guide explique comment préparer une favicon, la personnaliser dans Wix, la remplacer ou la supprimer, vérifier qu'elle fonctionne et résoudre les problèmes courants.

Qu'est-ce qu'un Favicon sur Wix ?

Un favicon est la petite image qui identifie votre site Web dans un navigateur. Les visiteurs peuvent le voir à côté du nom de votre site dans les onglets et les favoris du navigateur. Wix note également que les favicons peuvent apparaître à côté de l'URL de votre site dans les résultats de recherche lorsque les moteurs de recherche choisissent de les afficher.

Par exemple, une entreprise peut utiliser son logo complet dans l'en-tête du site Web, mais utiliser uniquement son symbole ou ses initiales comme favicon.

Une favicon est différente de votre :

  • Logo du site : L'image de marque plus grande affichée sur votre site Web.
  • Titre du site : Le texte qui peut apparaître comme titre de page ou de navigateur.
  • Icône de favori : La petite icône visuelle associée au site internet.

Un favicon doit donc être conçu pour être reconnu dans une très petite taille plutôt que de simplement le traiter comme une version miniature du logo complet du site Web.

De quoi avez-vous besoin avant de personnaliser votre favori Wix ?

Avant de télécharger un favicon, vérifiez à la fois les exigences de Wix et les exigences pratiques de conception.

Avez-vous besoin d'un forfait Wix Premium ?

Oui. Wix indique que vous avez besoin d'un forfait Premium et d'un domaine connecté pour ajouter une favicon personnalisée. Les sites Wix gratuits utilisent à la place le favicon Wix standard.

Votre site Wix doit-il être publié ?

Oui. Wix indique que votre site doit être publié avant que vous puissiez ajouter un favicon. Assurez-vous que vous travaillez avec le site et le domaine que les visiteurs utilisent réellement.

Quelle taille d'image doit avoir une favicon Wix ?

Wix exige que l'image du favicon soit un multiple de 48 pixels carrés, par exemple 48 × 48, 96 × 96 ou 144 × 144 pixels. Wix note une exception pour les fichiers SVG, qui n'ont pas besoin de suivre la même règle de dimension en pixels. Wix indique également que Google redimensionne les favicons à 16 × 16 pixels pour les résultats de recherche.

Quels formats de fichiers pouvez-vous utiliser pour une favicon Wix ?

Wix répertorie ICO, PNG, JPG et SVG comme formats de favicon appropriés. Le PNG est particulièrement utile pour les logos et les icônes car il permet de préserver la transparence.

Une favicon Wix peut-elle avoir un arrière-plan transparent ?

Oui. Wix indique spécifiquement qu'un arrière-plan transparent peut être utilisé lorsque le favicon est téléchargé au format PNG. Cela peut être utile lorsque votre logo ou icône n’a pas besoin d’un arrière-plan carré uni.

Qu'est-ce qui fait un bon Favicon ?

Un favicon doit être facile à reconnaître avec une très petite taille. Un logo qui semble excellent sur un en-tête de site Web volumineux peut devenir illisible lorsqu'il est réduit à un favicon.

  • Utilisation : Un symbole simple, une ou deux initiales, un contraste fort, des formes épurées et une marque reconnaissable.
  • Évitez : Noms d'entreprise longs, texte minuscule, illustrations très détaillées, lignes fines et trop d'éléments visuels.

Comment personnaliser le Favicon sur Wix ?

Pour les sites Wix utilisant Wix Editor ou Studio Editor, le flux de travail actuel du tableau de bord de Wix se fait via les paramètres du site Web.

  1. Ouvrez le tableau de bord de votre site Wix : Connectez-vous à votre compte Wix et ouvrez le tableau de bord du site Web dont vous souhaitez modifier la favicon. Si vous gérez plusieurs sites Web Wix, vérifiez le nom du site avant de continuer.
  2. Paramètres ouverts : Depuis le tableau de bord Wix, ouvrez Paramètres. Wix utilise la zone des paramètres pour gérer les informations clés du site Web, y compris le favicon du site.
  3. Ouvrez les paramètres du site Web : Sélectionnez Paramètres du site Web. Wix identifie les paramètres du site Web comme l'endroit où vous pouvez gérer les informations essentielles du site Web telles que le statut de publication, le nom du site, l'URL, le favicon et l'image de partage social.
  4. Recherchez la section Favicon : Recherchez la section Favicon. Vous devriez voir une option pour télécharger ou remplacer le favicon actuel.
  5. Téléchargez le Favicon : Cliquez Télécharger une image sous Favicon. Sélectionnez l'image préparée sur votre ordinateur. Le processus documenté de Wix est le suivant : paramètres, paramètres du site Web, cliquez sur Télécharger l'image, choisissez le fichier.
  6. Enregistrez les modifications : Après avoir sélectionné l'image, enregistrez le paramètre favicon. La documentation sur les paramètres du site Web de Wix indique qu'après avoir mis à jour les paramètres d'un site Web, vous devez cliquer sur Enregistrer.
  7. Consultez le site Web Live Wix : Ouvrez le site Web publié dans un navigateur. Regardez l'onglet du navigateur et vérifiez si votre favicon personnalisé apparaît à côté du nom du site. Ne comptez pas uniquement sur le tableau de bord Wix pour vérifier le résultat final.

Où est le paramètre Favicon dans Wix ?

L'emplacement exact dépend de l'éditeur Wix que vous utilisez.

Où se trouve le paramètre Favicon dans l'Éditeur Wix ?

Pour les sites créés avec l'Éditeur Wix, utilisez :

Wix Dashboard → Paramètres → Paramètres du site Web → Favicon

Où se trouve le paramètre Favicon dans Wix Studio ?

Les sites Wix Studio utilisent également le tableau de bord du site et les paramètres du site Web pour les informations essentielles au niveau du site. L'interface exacte peut être différente de l'éditeur Wix classique, mais le favicon reste un paramètre au niveau du site Web.

Où se trouve le paramètre Favicon dans l'éditeur Wix Harmony ?

Le nouvel éditeur Wix Harmony, sorti en janvier 2026, fournit un raccourci distinct :

Harmony Editor → Cliquez sur Nom du site (en haut à gauche) → Présentation du site → Ajouter un favicon

Cette variation est importante car les anciens didacticiels qui demandent à chaque utilisateur de Wix de naviguer dans les mêmes menus du tableau de bord peuvent ne pas correspondre à l'interface que vous voyez actuellement.

Comment personnaliser un favicon dans Wix Harmony Editor ?

Si vous utilisez le nouvel éditeur Wix Harmony, vous pouvez accéder au favicon directement depuis le panneau Présentation du site.

  1. Ouvrez le panneau de présentation du site : Ouvrez votre site Web dans Harmony Editor. Cliquez sur le nom de votre site en haut à gauche de l'éditeur.
  2. Cliquez sur Ajouter une icône de favori : Dans le panneau Présentation du site, recherchez Ajouter une icône de favori. Cliquez dessus pour commencer à télécharger l'icône.
  3. Téléchargez votre favicon : Sélectionnez l'image favicon que vous avez préparée. Utilisez une image qui respecte les exigences de Wix en matière de favicon.
  4. Enregistrez ou publiez les modifications : Terminez le téléchargement et publiez votre site Web si nécessaire afin que le changement soit reflété sur le site en direct.
  5. Vérifiez le favicon : Ouvrez le domaine en direct et vérifiez l'onglet du navigateur. Si le favicon précédent reste visible, testez le site dans une fenêtre de navigateur privée.

Comment créer un favicon pour Wix ?

Vous pouvez créer un favicon à partir d'un logo existant, d'un symbole de marque ou d'un simple design basé sur du texte.

Comment créer un Favicon à partir de votre logo ?

Commencez par la partie la plus reconnaissable du logo. Si votre logo contient un symbole et un long mot-symbole, envisagez d'utiliser uniquement le symbole. Réduire le mot-symbole complet à la taille d'un favicon peut rendre le texte illisible. Préservez le logo original et l'identité de la marque plutôt que de modifier le libellé ou de traduire le logo dans le cadre du processus de création du favicon.

Comment créer un Favicon à partir d'initiales ou de texte ?

Une ou deux initiales peuvent bien fonctionner lorsqu’une marque n’a pas de symbole autonome. Par exemple, une entreprise appelée North Star Digital pourrait utiliser N.-É. plutôt que d'essayer d'insérer le nom complet de l'entreprise dans le favicon. Utilisez de gros caractères, un espacement suffisant et un contraste fort.

Comment créer une icône simple pour votre site Web Wix ?

Utilisez une toile carrée et concentrez-vous sur un élément visuel reconnaissable. Un bon processus de départ est le suivant : choisissez le logo, le symbole ou les initiales, supprimez les détails inutiles, placez-le sur une toile carrée, utilisez un contraste fort, exportez-le et vérifiez l'icône en petite taille.

Comment convertir un PNG en favicon Wix ?

Si vous possédez déjà un logo ou une icône PNG, vous pouvez utiliser un outil de conversion de favicon pour le préparer. PNGversFavicon.com peut convertir un PNG existant en illustration favicon. Ceci est utile lorsque vous disposez déjà d’une image de marque adaptée et que vous devez la transformer en favicon dédié. Après la conversion, vérifiez que le fichier résultant respecte toujours les exigences des favicon de Wix (ICO, PNG, JPG ou SVG, les images non SVG doivent utiliser des dimensions carrées multiples de 48 pixels).

Quelle doit être la taille d'une favicon Wix ?

L'exigence actuelle de Wix est qu'un favicon doit être un multiple de 48 pixels carrés, sauf si vous utilisez un fichier SVG. Les exemples incluent 48 × 48 et 96 × 96 pixels.

La distinction importante se situe entre l'image téléchargée et la taille à laquelle un favicon est affiché. Un navigateur peut afficher le favicon dans une taille beaucoup plus petite que l'image d'origine. Wix indique également que Google redimensionne les favicons à 16 × 16 pixels pour les résultats de recherche. Par conséquent, un favicon techniquement valide peut toujours être un mauvais favicon si son texte ou ses graphiques sont trop détaillés.

Comment vérifier si votre favori Wix fonctionne ?

Après avoir téléchargé le favicon, vérifiez le site Web en direct plutôt que de supposer que le téléchargement a réussi simplement parce que l'image apparaît dans les paramètres Wix.

  • Vérifiez l'onglet Navigateur : Ouvrez votre site Web publié. Le favicon doit apparaître à côté du nom du site Web ou de la page dans l’onglet du navigateur.
  • Vérifiez vos favoris : Ajoutez le site à vos favoris et vérifiez l’entrée du favori. Les favicons sont couramment utilisés dans les interfaces de signets.
  • Testez le site Web en direct : Assurez-vous de vérifier le domaine publié, pas seulement l'éditeur ou le tableau de bord.
  • Testez dans une fenêtre privée ou incognito : Ouvrez une fenêtre privée ou incognito et visitez le site. Cela peut révéler si votre navigateur normal affiche une ancienne favicon en cache.
  • Testez un autre navigateur : Ouvrez le même site Web dans un autre navigateur. Si le nouveau favicon apparaît dans un navigateur et pas dans un autre, la mise en cache du navigateur est une explication probable.

Pourquoi mon favori Wix ne s'affiche-t-il pas ?

Plusieurs problèmes peuvent faire apparaître le favicon manquant.

Vous n'avez pas le forfait Wix requis

Problème: Wix nécessite un forfait Premium et un domaine connecté pour un favicon personnalisé.
Réparer: Vérifiez votre forfait et confirmez que votre domaine personnalisé est connecté au site.

Votre site Web n'a pas été publié

Problème: Wix déclare que le site doit être publié avant d'ajouter un favicon.
Réparer: Publiez le site Web, puis revenez aux paramètres du favicon.

Vous avez modifié le mauvais site Wix

Problème: Votre compte gère plusieurs sites et vous avez modifié le favicon d'un autre site.
Réparer: Vérifiez le nom du site et le domaine connecté avant de modifier.

Vous avez téléchargé une image inappropriée

Problème: L'image ne répond pas aux dimensions requises ou utilise un format que Wix ne prend pas en charge.
Réparer: Utilisez ICO, PNG, JPG ou SVG et assurez-vous qu'un favicon non-SVG utilise des dimensions carrées qui sont un multiple de 48 pixels.

Votre navigateur a mis en cache l'ancien Favicon

Problème: L’ancienne favicon reste visible une fois que vous l’avez modifiée avec succès.
Réparer: Testez le site Web dans une fenêtre privée ou dans un autre navigateur. Effacez les données du navigateur mises en cache si nécessaire.

Vous testez l'éditeur au lieu du site Web en direct

Problème: Le favicon semble incorrect lorsque vous travaillez dans Wix.
Réparer: Ouvrez le domaine publié et vérifiez l'onglet du navigateur.

Google n'a pas mis à jour le Favicon dans la recherche

Problème: Un favicon apparaissant dans la recherche Google est distinct du favicon correctement configuré sur Wix. Wix déclare que l'indexation est contrôlée par Google et que Wix ne peut garantir le moment où Google affichera le favicon.
Réparer: Confirmez d’abord que le favicon fonctionne sur le site Web en direct. Traitez l'affichage de la recherche Google comme un processus distinct.

Comment réparer une favicon Wix qui ne se met pas à jour ?

Effectuez les vérifications dans cet ordre :

  1. Confirmez que vous disposez d'un forfait Premium et que votre domaine est connecté.
  2. Confirmez que le site est publié.
  3. Ouvrez le bon site Wix dans votre tableau de bord.
  4. Aller à Paramètres → Paramètres du site Web → Favicon.
  5. Confirmez que la bonne image est sélectionnée et cliquez sur Enregistrer.
  6. Ouvrez le domaine publié et testez dans une fenêtre privée/incognito ou dans un autre navigateur.
  7. Videz le cache du navigateur si l'icône précédente continue d'apparaître.

Si le problème concerne uniquement la recherche Google, autorisez le processus d'exploration et d'indexation distinct de Google. Cette séquence sépare les problèmes de configuration de Wix de la mise en cache du navigateur et du comportement du moteur de recherche.

Comment modifier ou remplacer une icône de favori Wix ?

Le remplacement d'un favicon existant utilise la même zone de paramètres.

  • Ouvrez le tableau de bord de votre site Wix et cliquez sur Paramètres.
  • Ouvert Paramètres du site Web.
  • Recherchez la section Favicon et cliquez sur l’option télécharger/remplacer l’image.
  • Sélectionnez votre nouveau favicon et enregistrez la modification.
  • Publiez le site si nécessaire, puis ouvrez le site en direct et vérifiez.

La documentation actuelle sur les paramètres du site Web de Wix confirme que le favicon peut être téléchargé ou remplacé à partir de cette zone. Pour les utilisateurs d'Harmony Editor, l'autre solution consiste à ouvrir le panneau Présentation du site et à cliquer sur Ajouter un favori.

Comment supprimer une favicon Wix ?

Le processus de suppression dépend de l'interface Wix actuelle et de la façon dont le favicon du site est géré.

Ouvrez les paramètres du favicon du site et recherchez l'option disponible pour supprimer, remplacer ou réinitialiser le favicon actuel. Ne présumez pas que chaque interface Wix expose un bouton de suppression portant le même nom.

Il existe également une distinction importante entre la suppression d'un favicon personnalisé et la suppression de la marque Wix. Wix indique que les sites gratuits utilisent le favicon Wix, tandis qu'un favicon personnalisé nécessite le plan Premium approprié et le domaine connecté.

Pouvez-vous ajouter une favicon Wix avec un code personnalisé ?

Normalement, aucun code personnalisé n'est nécessaire. Wix fournit un paramètre natif de favicon via les paramètres du site Web, et le nouvel éditeur Harmony fournit un contrôle direct Ajouter un favicon.

Quand devriez-vous utiliser le paramètre Favicon intégré de Wix ?

Utilisez le paramètre intégré de Wix chaque fois qu'il est disponible. Il est plus simple à gérer et évite des modifications inutiles dans la mise en œuvre du site.

Quand un code personnalisé peut-il être nécessaire ?

Le code personnalisé n’est généralement pertinent que pour les implémentations inhabituelles ou hautement personnalisées. Ne modifiez pas le code de votre site simplement parce qu'un didacticiel écrit pour une ancienne interface Wix montre une méthode de favicon basée sur le code.

Pouvez-vous utiliser votre logo comme favori Wix ?

Oui. Wix note spécifiquement que la plupart des entreprises utilisent leur propre logo pour le favicon. Cependant, le logo complet n’est pas toujours le meilleur choix.

Devriez-vous utiliser le logo complet ?

Utilisez le logo complet uniquement lorsqu'il reste reconnaissable à la taille d'un favicon. Un mot-symbole horizontal comportant plusieurs mots peut devenir trop petit pour être lu.

Quand devriez-vous plutôt utiliser un symbole ou des initiales ?

Utilisez la partie la plus reconnaissable de votre marque lorsque le logo complet contient trop de détails. Un symbole, un monogramme ou une ou deux initiales peuvent créer un favicon plus fort.

Erreurs courantes de Wix Favicon à éviter

  • Utiliser les mauvaises dimensions : Pour les favicons non SVG, utilisez des dimensions carrées multiples de 48 pixels.
  • Utiliser un logo inutilement compliqué : Réduisez le nombre d’éléments pour que l’icône reste reconnaissable.
  • Utiliser un petit texte : Le texte lisible dans un grand logo peut devenir invisible dans un favicon.
  • Utilisation d'un mauvais contraste : Faites en sorte que l'icône soit distincte de son arrière-plan.
  • Téléchargement d'illustrations de mauvaise qualité : Commencez avec une image source propre.
  • Oublier l'exigence du plan Premium : Un favicon personnalisé nécessite un forfait Premium et un domaine connecté.
  • Oublier de publier : Wix exige que le site Web soit publié avant d'ajouter un favicon.
  • Vérification d'un seul navigateur : Une favicon en cache peut faire ressembler une mise à jour réussie à un échec de téléchargement.
  • En attendant que Google mette à jour immédiatement : Google contrôle quand il explore et affiche les favicons. Wix ne peut pas garantir quand cela se produira.
  • Confondre le favicon avec le titre du navigateur : Changer votre favicon change la petite icône. Cela ne modifie pas automatiquement le texte affiché comme titre de la page.

FAQ sur les icônes de favoris Wix

Puis-je ajouter une favicon à Wix gratuitement ?

Non. Wix indique que l'ajout d'un favicon personnalisé nécessite un forfait Premium et un domaine connecté. Les sites Wix gratuits utilisent le favicon Wix standard.

Quelle doit être la taille d'une favicon Wix ?

Pour les fichiers non SVG, le favicon doit être un multiple de 48 pixels carrés, par exemple 48 × 48 ou 96 × 96 pixels. Les fichiers SVG sont exemptés de cette exigence de dimension en pixels.

Quel format de fichier Wix utilise-t-il pour les favicons ?

Wix prend en charge les formats de favicon appropriés, notamment ICO, PNG, JPG et SVG.

Puis-je utiliser un PNG comme favori Wix ?

Oui. PNG est pris en charge, y compris les images PNG avec un arrière-plan transparent.

Puis-je utiliser un SVG comme favori Wix ?

Oui. Wix répertorie SVG comme format de favicon pris en charge, et SVG est exempté de l'exigence de multiple de 48 pixels.

Puis-je utiliser mon logo comme favori Wix ?

Oui. Un logo est un choix courant, mais simplifiez-le si nécessaire pour qu'il reste reconnaissable même dans une petite taille. Wix note que la plupart des entreprises utilisent leur propre logo comme favicon.

Pourquoi mon favori Wix ne s'affiche-t-il pas ?

Confirmez que votre site dispose du forfait Premium requis et du domaine connecté, que le site est publié et que vous avez téléchargé le favicon sur le bon site Wix. Testez ensuite le site en direct dans une fenêtre privée ou dans un autre navigateur pour exclure la mise en cache.

Pourquoi le logo Wix s'affiche-t-il toujours comme mon favicon ?

Les sites Wix gratuits utilisent le favicon Wix. Un favicon personnalisé nécessite un forfait Premium et un domaine connecté.

Comment changer mon favicon sur Wix ?

Accédez à Paramètres → Paramètres du site Web → Favicon, téléchargez ou remplacez l'image et enregistrez la modification. Dans le nouveau Harmony Editor, vous pouvez également ouvrir le panneau Présentation du site et cliquer sur Ajouter un favori.

Comment supprimer une favicon Wix ?

Ouvrez les commandes de favicon dans les param��tres de votre site Wix et utilisez l'option de suppression, de remplacement ou de réinitialisation disponible. Le contrôle exact peut varier selon l'interface Wix.

Combien de temps faut-il pour mettre à jour une favicon Wix ?

Il n’existe pas d’heure d’affichage universelle. Vos paramètres Wix peuvent être mis à jour pendant que votre navigateur continue d'afficher une favicon en cache. La recherche Google a un processus d'exploration et d'indexation distinct, et Wix ne garantit pas quand Google affichera le favicon mis à jour.

Pourquoi mon favori Wix n'apparaît-il pas dans la recherche Google ?

Wix indique que Google décide quand indexer un favicon et s'il doit l'afficher dans les résultats de recherche. Un favicon fonctionnant correctement dans votre navigateur ne garantit pas que Google l'affichera immédiatement à côté de votre liste de recherche.

Dois-je publier mon site Wix avant d'ajouter un favicon ?

Oui. La documentation des favicon de Wix indique que le site doit être publié avant que vous puissiez ajouter un favicon.

Ai-je besoin d'un forfait Wix Premium pour ajouter une favicon ?

Oui. Wix nécessite un forfait Premium et un domaine connecté pour un favicon personnalisé.

Comment créer un favicon avant de le télécharger sur Wix

Utilisez ce workflow si vous n'avez pas déjà de favicon :

  1. Commencez par votre logo, votre symbole ou vos initiales. Gardez le logo original et l’identité de la marque inchangés.
  2. Simplifiez l’illustration pour un affichage à petite échelle.
  3. Créez une image carrée (pour les fichiers non SVG, utilisez des dimensions multiples de 48 pixels).
  4. Exportez l'image au format PNG, JPG, ICO ou SVG.
  5. Vérifiez le favicon en petite taille.
  6. Utilisez un convertisseur de favicon tel que PNGversFavicon.com lorsque vous avez déjà un PNG qui doit être converti.
  7. Téléchargez le favicon terminé sur Wix.
  8. Enregistrez et publiez le site.
  9. Consultez le site Web en direct dans un onglet du navigateur.

Conclusion

Pour personnaliser un favicon sur Wix, préparez une simple icône carrée, puis ouvrez Paramètres → Paramètres du site Web → Favicon et téléchargez l'image. Enregistrez la modification et vérifiez le résultat sur le site Web publié. Si vous utilisez le nouvel éditeur Wix Harmony, vous pouvez accéder à la même tâche directement via Présentation du site → Ajouter un favicon. Les deux exigences les plus importantes sont le forfait Premium de Wix avec un domaine connecté et un site publié. Si le favicon n'apparaît toujours pas après l'enregistrement, testez le site en direct dans une fenêtre privée ou dans un autre navigateur. La visibilité de la recherche Google est un processus distinct contrôlé par Google.
