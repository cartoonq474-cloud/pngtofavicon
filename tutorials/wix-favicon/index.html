How to Customize Favicon on Wix

Wix lets you remove default icons on premium plans. Customize your favicon to boost store design consistency.

A favicon is the small icon that represents your Wix website in browser tabs, bookmarks, and other browser interfaces. Wix provides a built-in favicon setting, so you do not normally need to edit your site's code.

For standard Wix sites, you need a Premium plan and a connected domain to add a custom favicon, and Wix requires the site to be published before you add one. The current Wix workflow uses Website Settings, while the newer Wix Harmony Editor also provides an Add Favicon option directly from its Site Overview panel.

This guide explains how to prepare a favicon, customize it in Wix, replace or remove it, verify that it works, and troubleshoot common problems.

What Is a Favicon on Wix?

A favicon is the small image that identifies your website in a browser. Visitors can see it next to your site's name in browser tabs and bookmarks. Wix also notes that favicons can appear alongside your site's URL in search results when search engines choose to display them.

For example, a business might use its full logo in the website header but use only its symbol or initials as the favicon.

A favicon is different from your:

  • Site logo: The larger brand image displayed within your website.
  • Site title: The text that can appear as the page or browser title.
  • Favicon: The small visual icon associated with the website.

A favicon should therefore be designed for recognition at a very small size rather than simply treating it as a miniature version of the full website logo.

What Do You Need Before Customizing Your Wix Favicon?

Before uploading a favicon, check both the Wix requirements and the practical design requirements.

Do You Need a Wix Premium Plan?

Yes. Wix states that you need a Premium plan and a connected domain to add a custom favicon. Free Wix sites use the standard Wix favicon instead.

Does Your Wix Site Need to Be Published?

Yes. Wix states that your site must be published before you can add a favicon. Make sure you are working with the site and domain that visitors actually use.

What Image Size Should a Wix Favicon Be?

Wix requires the favicon image to be a multiple of 48 pixels square, such as 48 × 48, 96 × 96, or 144 × 144 pixels. Wix notes an exception for SVG files, which do not need to follow the same pixel-dimension rule. Wix also states that Google rescales favicons to 16 × 16 pixels for search results.

Which File Formats Can You Use for a Wix Favicon?

Wix lists ICO, PNG, JPG, and SVG as suitable favicon formats. PNG is particularly useful for logos and icons because it can preserve transparency.

Can a Wix Favicon Have a Transparent Background?

Yes. Wix specifically states that a transparent background can be used when the favicon is uploaded as a PNG. This can be useful when your logo or icon does not need a solid square background.

What Makes a Good Favicon?

A favicon should be easy to recognize at a very small size. A logo that looks excellent on a large website header can become unreadable when reduced to a favicon.

  • Use: A simple symbol, one or two initials, strong contrast, clean shapes, and a recognizable brand mark.
  • Avoid: Long business names, tiny text, highly detailed illustrations, thin lines, and too many visual elements.

How Do You Customize the Favicon on Wix?

For Wix sites using the Wix Editor or Studio Editor, Wix's current dashboard workflow is through Website Settings.

  1. Open Your Wix Site Dashboard: Log in to your Wix account and open the dashboard for the website whose favicon you want to change. If you manage multiple Wix websites, verify the site name before continuing.
  2. Open Settings: From the Wix dashboard, open Settings. Wix uses the settings area to manage key website information, including the site's favicon.
  3. Open Website Settings: Select Website settings. Wix identifies Website Settings as the place where you can manage essential website information such as the publish status, site name, URL, favicon, and social sharing image.
  4. Find the Favicon Section: Look for the Favicon section. You should see an option to upload or replace the current favicon.
  5. Upload the Favicon: Click Upload Image under Favicon. Select the prepared image from your computer. Wix's documented process is: settings, Website settings, click Upload Image, choose the file.
  6. Save the Changes: After selecting the image, save the favicon setting. Wix's Website Settings documentation states that after updating a website setting, you should click Save.
  7. Check the Live Wix Website: Open the published website in a browser. Look at the browser tab and check whether your custom favicon appears beside the site's name. Do not rely only on the Wix dashboard to verify the final result.

Where Is the Favicon Setting in Wix?

The exact location depends on which Wix editor you are using.

Where Is the Favicon Setting in Wix Editor?

For sites built with the Wix Editor, use:

Wix Dashboard → Settings → Website settings → Favicon

Where Is the Favicon Setting in Wix Studio?

Wix Studio sites also use the site's dashboard and Website Settings for essential site-level information. The exact interface can look different from the classic Wix Editor, but the favicon remains a website-level setting.

Where Is the Favicon Setting in the Wix Harmony Editor?

The newer Wix Harmony Editor, released in January 2026, provides a separate shortcut:

Harmony Editor → Click Site Name (top-left) → Site Overview → Add Favicon

This variation is important because older tutorials that tell every Wix user to navigate through the same dashboard menus may not match the interface you currently see.

How Do You Customize a Favicon in Wix Harmony Editor?

If you are using the newer Wix Harmony Editor, you can access the favicon directly from the Site Overview panel.

  1. Open the Site Overview Panel: Open your website in the Harmony Editor. Click your site's name at the top-left of the editor.
  2. Click Add Favicon: In the Site Overview panel, find Add Favicon. Click it to start uploading the icon.
  3. Upload Your Favicon: Select the favicon image you prepared. Use an image that follows Wix's favicon requirements.
  4. Save or Publish the Changes: Complete the upload and publish your website when necessary so the change is reflected on the live site.
  5. Verify the Favicon: Open the live domain and check the browser tab. If the previous favicon remains visible, test the site in a private browser window.

How Do You Create a Favicon for Wix?

You can create a favicon from an existing logo, a brand symbol, or a simple text-based design.

How Do You Create a Favicon From Your Logo?

Start with the most recognizable part of the logo. If your logo contains a symbol and a long wordmark, consider using only the symbol. Reducing the complete wordmark to favicon size can make the text unreadable. Preserve the original logo and brand identity rather than changing the wording or translating the logo as part of the favicon creation process.

How Do You Create a Favicon From Initials or Text?

One or two initials can work well when a brand does not have a standalone symbol. For example, a business called North Star Digital could use NS rather than trying to fit the complete business name into the favicon. Use large lettering, sufficient spacing, and strong contrast.

How Do You Create a Simple Icon for Your Wix Website?

Use a square canvas and focus on one recognizable visual element. A good starting process is: choose the logo, symbol, or initials, remove unnecessary details, place it on a square canvas, use strong contrast, export it, and check the icon at small sizes.

How Do You Convert a PNG Into a Wix Favicon?

If you already have a PNG logo or icon, you can use a favicon conversion tool to prepare it. PNGtoFavicon.com can convert an existing PNG into favicon artwork. This is useful when you already have a suitable brand image and need to turn it into a dedicated favicon. After conversion, verify that the resulting file still follows Wix's favicon requirements (ICO, PNG, JPG, or SVG, non-SVG images must use square dimensions that are multiples of 48 pixels).

What Size Should a Wix Favicon Be?

Wix's current requirement is that a favicon should be a multiple of 48 pixels square, unless you are using an SVG file. Examples include 48 × 48 and 96 × 96 pixels.

The important distinction is between the uploaded image and the size at which a favicon is displayed. A browser may display the favicon at a much smaller size than the original image. Wix also states that Google rescales favicons to 16 × 16 pixels for search results. Therefore, a technically valid favicon can still be a poor favicon if its text or graphics are too detailed.

How Do You Check if Your Wix Favicon Is Working?

After uploading the favicon, check the live website rather than assuming the upload succeeded just because the image appears in the Wix settings.

  • Check the Browser Tab: Open your published website. The favicon should appear beside the website or page name in the browser tab.
  • Check Your Bookmarks: Bookmark the site and check the bookmark entry. Favicons are commonly used in bookmark interfaces.
  • Test the Live Website: Make sure you are checking the published domain, not only the editor or dashboard.
  • Test in a Private or Incognito Window: Open a private or incognito window and visit the site. This can reveal whether your normal browser is displaying an older cached favicon.
  • Test Another Browser: Open the same website in another browser. If the new favicon appears in one browser and not another, browser caching is a likely explanation.

Why Is My Wix Favicon Not Showing?

Several issues can cause the favicon to appear missing.

You Do Not Have the Required Wix Plan

Problem: Wix requires a Premium plan and a connected domain for a custom favicon.
Fix: Check your plan and confirm that your custom domain is connected to the site.

Your Website Has Not Been Published

Problem: Wix states that the site needs to be published before adding a favicon.
Fix: Publish the website, then return to the favicon settings.

You Edited the Wrong Wix Site

Problem: Your account manages multiple sites and you changed a different site's favicon.
Fix: Check the site name and connected domain before editing.

You Uploaded an Unsuitable Image

Problem: The image does not meet the required dimensions or uses a format that Wix does not support.
Fix: Use ICO, PNG, JPG, or SVG and make sure a non-SVG favicon uses square dimensions that are a multiple of 48 pixels.

Your Browser Has Cached the Old Favicon

Problem: The old favicon remains visible after you successfully change it.
Fix: Test the website in a private window or another browser. Clear cached browser data if necessary.

You Are Testing the Editor Instead of the Live Website

Problem: The favicon appears incorrect while working inside Wix.
Fix: Open the published domain and check the browser tab there.

Google Has Not Updated the Favicon in Search

Problem: A favicon appearing in Google Search is separate from the favicon being correctly configured on Wix. Wix states that indexing is controlled by Google and that Wix cannot guarantee when Google will display the favicon.
Fix: First confirm that the favicon works on the live website. Treat Google Search display as a separate process.

How Do You Fix a Wix Favicon That Is Not Updating?

Work through the checks in this order:

  1. Confirm you have a Premium plan and your domain is connected.
  2. Confirm the site is published.
  3. Open the correct Wix site in your dashboard.
  4. Go to Settings → Website settings → Favicon.
  5. Confirm the correct image is selected and click Save.
  6. Open the published domain, and test in a private/incognito window or another browser.
  7. Clear browser cache if the previous icon continues to appear.

If the issue only concerns Google Search, allow for Google's separate crawling and indexing process. This sequence separates Wix configuration problems from browser caching and search-engine behavior.

How Do You Change or Replace a Wix Favicon?

Replacing an existing favicon uses the same settings area.

  • Open your Wix site dashboard and click Settings.
  • Open Website settings.
  • Find the Favicon section and click the upload/replace image option.
  • Select your new favicon and save the change.
  • Publish the site when required, then open the live site and verify.

Wix's current Website Settings documentation confirms that the favicon can be uploaded or replaced from this area. For Harmony Editor users, the alternative route is to open the Site Overview panel and click Add Favicon.

How Do You Remove a Wix Favicon?

The removal process depends on the current Wix interface and how the site's favicon is managed.

Open the site's favicon settings and look for the available option for removing, replacing, or resetting the current favicon. Do not assume that every Wix interface exposes an identically named removal button.

There is also an important distinction between removing a custom favicon and removing Wix branding. Wix states that free sites use the Wix favicon, while a custom favicon requires the appropriate Premium plan and connected domain.

Can You Add a Wix Favicon With Custom Code?

Normally, no custom code is necessary. Wix provides a native favicon setting through Website Settings, and the newer Harmony Editor provides a direct Add Favicon control.

When Should You Use Wix's Built-In Favicon Setting?

Use Wix's built-in setting whenever it is available. It is simpler to manage and avoids unnecessary changes to the site's implementation.

When Might Custom Code Be Necessary?

Custom code is generally relevant only for unusual or highly customized implementations. Do not modify your site's code simply because a tutorial written for an older Wix interface shows a code-based favicon method.

Can You Use Your Logo as a Wix Favicon?

Yes. Wix specifically notes that most companies use their own logo for the favicon. However, the full logo may not always be the best choice.

Should You Use the Full Logo?

Use the full logo only when it remains recognizable at favicon size. A horizontal wordmark with several words can become too small to read.

When Should You Use a Symbol or Initials Instead?

Use the most recognizable part of your brand when the full logo contains too much detail. A symbol, monogram, or one or two initials can make a stronger favicon.

Common Wix Favicon Mistakes to Avoid

  • Using the wrong dimensions: For non-SVG favicons, use square dimensions that are multiples of 48 pixels.
  • Using an unnecessarily complicated logo: Reduce the number of elements so the icon remains recognizable.
  • Using tiny text: Text that is readable in a large logo may become invisible in a favicon.
  • Using poor contrast: Make the icon distinct from its background.
  • Uploading low-quality artwork: Start with a clean source image.
  • Forgetting the Premium plan requirement: A custom favicon requires a Premium plan and connected domain.
  • Forgetting to publish: Wix requires the website to be published before adding a favicon.
  • Checking only one browser: A cached favicon can make a successful update look like a failed upload.
  • Expecting Google to update immediately: Google controls when it crawls and displays favicons. Wix cannot guarantee when that will happen.
  • Confusing the favicon with the browser title: Changing your favicon changes the small icon. It does not automatically change the text shown as the page title.

Yes. PNG is supported, including PNG images with transparent backgrounds.

How Do I Remove a Wix Favicon?

Why Is My Wix Favicon Not Showing in Google Search?

Wix states that Google decides when to index a favicon and whether to display it in search results. A favicon working correctly in your browser does not guarantee that Google will immediately display it beside your search listing.
