So passen Sie Favicon an Wix

Mit Wix können Sie Standardsymbole in Premium-Plänen entfernen. Passen Sie Ihr Favicon an, um die Konsistenz des Shop-Designs zu verbessern.

Ein Favicon ist das kleine Symbol, das Ihre Wix-Website in Browser-Tabs, Lesezeichen und anderen Browseroberflächen darstellt. Wix bietet eine integrierte Favicon-Einstellung, sodass Sie den Code Ihrer Website normalerweise nicht bearbeiten müssen.

Für Standard-Websites von Wix benötigen Sie einen Premium-Plan und eine verbundene Domain, um ein benutzerdefiniertes Favicon hinzuzufügen, und Wix erfordert, dass die Website veröffentlicht wird, bevor Sie eines hinzufügen. Der aktuelle Wix-Workflow verwendet Website-Einstellungen, während der neuere Wix Harmony Editor auch eine Option zum Hinzufügen von Favicon direkt im Bereich „Site-Übersicht“ bietet.

In dieser Anleitung wird erläutert, wie Sie ein Favicon vorbereiten, es in Wix anpassen, es ersetzen oder entfernen, überprüfen, ob es funktioniert, und häufige Probleme beheben.

Was ist ein Favicon bei Wix?

Ein Favicon ist das kleine Bild, das Ihre Website in einem Browser identifiziert. Besucher können es neben dem Namen Ihrer Website in Browser-Registerkarten und Lesezeichen sehen. Wix weist außerdem darauf hin, dass Favicons neben der URL Ihrer Website in den Suchergebnissen erscheinen können, wenn Suchmaschinen sie anzeigen.

Beispielsweise könnte ein Unternehmen sein vollständiges Logo im Header der Website verwenden, aber nur sein Symbol oder seine Initialen als Favicon verwenden.

Ein Favicon unterscheidet sich von Ihrem:

  • Site-Logo: Das größere Markenbild, das auf Ihrer Website angezeigt wird.
  • Titel der Website: Der Text, der als Seiten- oder Browsertitel angezeigt werden kann.
  • Favicon: Das kleine visuelle Symbol, das mit der Website verknüpft ist.

Ein Favicon sollte daher so konzipiert sein, dass es in sehr kleiner Größe erkennbar ist, und es nicht einfach als Miniaturversion des vollständigen Website-Logos betrachten.

Was benötigen Sie, bevor Sie Ihr Wix-Favicon anpassen?

Bevor Sie ein Favicon hochladen, prüfen Sie sowohl die Wix-Anforderungen als auch die praktischen Designanforderungen.

Benötigen Sie einen Premium-Plan von Wix?

Ja. Wix gibt an, dass Sie einen Premium-Plan und eine verbundene Domain benötigen, um ein benutzerdefiniertes Favicon hinzuzufügen. Kostenlose Websites von Wix verwenden stattdessen das Standard-Favicon von Wix.

Muss Ihre Wix-Site veröffentlicht werden?

Ja. Wix gibt an, dass Ihre Website veröffentlicht werden muss, bevor Sie ein Favicon hinzufügen können. Stellen Sie sicher, dass Sie mit der Website und Domain arbeiten, die Besucher tatsächlich nutzen.

Welche Bildgröße sollte ein Wix-Favicon haben?

Wix verlangt, dass das Favicon-Bild ein Vielfaches von 48 Pixeln im Quadrat ist, beispielsweise 48 × 48, 96 × 96 oder 144 × 144 Pixel. Wix weist auf eine Ausnahme für SVG-Dateien hin, die nicht derselben Pixeldimensionsregel folgen müssen. Wix gibt außerdem an, dass Google die Favicons für Suchergebnisse auf 16 × 16 Pixel neu skaliert.

Welche Dateiformate können Sie für ein Wix-Favicon verwenden?

Wix listet ICO, PNG, JPG und SVG als geeignete Favicon-Formate auf. PNG eignet sich besonders für Logos und Symbole, da es die Transparenz bewahren kann.

Kann ein Favicon von Wix einen transparenten Hintergrund haben?

Ja. Wix gibt ausdrücklich an, dass ein transparenter Hintergrund verwendet werden kann, wenn das Favicon als PNG hochgeladen wird. Dies kann nützlich sein, wenn Ihr Logo oder Symbol keinen einfarbigen quadratischen Hintergrund benötigt.

Was macht ein gutes Favicon aus?

Ein Favicon sollte bei sehr kleiner Größe leicht zu erkennen sein. Ein Logo, das in einem großen Website-Header hervorragend aussieht, kann unleserlich werden, wenn es auf ein Favicon reduziert wird.

  • Verwendung: Ein einfaches Symbol, ein oder zwei Initialen, starker Kontrast, klare Formen und ein erkennbares Markenzeichen.
  • Vermeiden Sie: Lange Firmennamen, kleiner Text, sehr detaillierte Illustrationen, dünne Linien und zu viele visuelle Elemente.

Wie passt man das Favicon bei Wix an?

Für Websites von Wix, die den Wix Editor oder Studio Editor verwenden, erfolgt der aktuelle Dashboard-Workflow von Wix über die Website-Einstellungen.

  1. Öffnen Sie Ihr Site-Dashboard von Wix: Melden Sie sich bei Ihrem Wix-Konto an und öffnen Sie das Dashboard für die Website, deren Favicon Sie ändern möchten. Wenn Sie mehrere Websites von Wix verwalten, überprüfen Sie den Namen der Website, bevor Sie fortfahren.
  2. Öffnen Sie die Einstellungen: Öffnen Sie das Wix-Dashboard Einstellungen. Wix verwendet den Einstellungsbereich, um wichtige Website-Informationen zu verwalten, einschließlich des Favicons der Website.
  3. Öffnen Sie die Website-Einstellungen: Auswählen Website-Einstellungen. Wix identifiziert Website-Einstellungen als den Ort, an dem Sie wichtige Website-Informationen wie Veröffentlichungsstatus, Site-Name, URL, Favicon und Social-Sharing-Bild verwalten können.
  4. Finden Sie den Favicon-Bereich: Suchen Sie nach dem Favicon-Bereich. Sie sollten eine Option zum Hochladen oder Ersetzen des aktuellen Favicons sehen.
  5. Laden Sie das Favicon hoch: Klicken Sie Bild hochladen unter Favicon. Wählen Sie das vorbereitete Bild von Ihrem Computer aus. Der dokumentierte Prozess von Wix ist: Einstellungen, Website-Einstellungen, klicken Sie auf Bild hochladen, wählen Sie die Datei aus.
  6. Speichern Sie die Änderungen: Speichern Sie nach Auswahl des Bildes die Favicon-Einstellung. In der Dokumentation zu den Website-Einstellungen von Wix heißt es, dass Sie nach dem Aktualisieren einer Website-Einstellung auf klicken sollten Speichern.
  7. Schauen Sie sich die Website von Live Wix an: Öffnen Sie die veröffentlichte Website in einem Browser. Sehen Sie sich die Browser-Registerkarte an und prüfen Sie, ob Ihr benutzerdefiniertes Favicon neben dem Namen der Website angezeigt wird. Verlassen Sie sich nicht nur auf das Wix-Dashboard, um das Endergebnis zu überprüfen.

Wo ist die Favicon-Einstellung bei Wix?

Der genaue Speicherort hängt davon ab, welchen Wix-Editor Sie verwenden.

Wo ist die Favicon-Einstellung im Wix Editor?

Für Websites, die mit dem Wix Editor erstellt wurden, verwenden Sie:

Wix Dashboard → Einstellungen → Website-Einstellungen → Favicon

Wo ist die Favicon-Einstellung in Wix Studio?

Websites von Wix Studio nutzen außerdem das Dashboard und die Website-Einstellungen der Website für wichtige Informationen auf Website-Ebene. Die genaue Benutzeroberfläche kann vom klassischen Wix-Editor abweichen, das Favicon bleibt jedoch eine Einstellung auf Website-Ebene.

Wo ist die Favicon-Einstellung im Wix Harmony Editor?

Der neuere Wix Harmony Editor, der im Januar 2026 veröffentlicht wurde, bietet eine separate Verknüpfung:

Harmony Editor → Klicken Sie auf Site-Name (oben links) → Site-Übersicht → Favicon hinzufügen

Diese Variante ist wichtig, da ältere Tutorials, die jeden Wix-Benutzer anweisen, durch dieselben Dashboard-Menüs zu navigieren, möglicherweise nicht mit der Benutzeroberfläche übereinstimmen, die Sie derzeit sehen.

Wie passt man ein Favicon im Wix Harmony Editor an?

Wenn Sie den neueren Wix Harmony Editor verwenden, können Sie direkt über das Site-Übersichtsfenster auf das Favicon zugreifen.

  1. Öffnen Sie das Site-Übersichtsfenster: Öffnen Sie Ihre Website im Harmony Editor. Klicken Sie oben links im Editor auf den Namen Ihrer Website.
  2. Klicken Sie auf Favicon hinzufügen: Suchen Sie im Bereich „Site-Übersicht“ nach Favicon hinzufügen. Klicken Sie darauf, um mit dem Hochladen des Symbols zu beginnen.
  3. Laden Sie Ihr Favicon hoch: Wählen Sie das von Ihnen vorbereitete Favicon-Bild aus. Verwenden Sie ein Bild, das den Favicon-Anforderungen von Wix entspricht.
  4. Speichern oder veröffentlichen Sie die Änderungen: Schließen Sie den Upload ab und veröffentlichen Sie Ihre Website bei Bedarf, damit die Änderung auf der Live-Site widergespiegelt wird.
  5. Überprüfen Sie das Favicon: Öffnen Sie die Live-Domain und überprüfen Sie die Browser-Registerkarte. Wenn das vorherige Favicon weiterhin sichtbar ist, testen Sie die Site in einem privaten Browserfenster.

Wie erstellt man ein Favicon für Wix?

Sie können ein Favicon aus einem vorhandenen Logo, einem Markensymbol oder einem einfachen textbasierten Design erstellen.

Wie erstellen Sie ein Favicon aus Ihrem Logo?

Beginnen Sie mit dem erkennbarsten Teil des Logos. Wenn Ihr Logo ein Symbol und eine lange Wortmarke enthält, sollten Sie erwägen, nur das Symbol zu verwenden. Das Verkleinern der gesamten Wortmarke auf die Favicon-Größe kann dazu führen, dass der Text unleserlich wird. Behalten Sie das ursprüngliche Logo und die Markenidentität bei, anstatt den Wortlaut zu ändern oder das Logo im Rahmen des Favicon-Erstellungsprozesses zu übersetzen.

Wie erstellt man ein Favicon aus Initialen oder Text?

Ein oder zwei Initialen können gut funktionieren, wenn eine Marke kein eigenständiges Symbol hat. Beispielsweise könnte ein Unternehmen namens North Star Digital dies nutzen NS anstatt zu versuchen, den vollständigen Firmennamen in das Favicon einzufügen. Verwenden Sie große Schrift, ausreichend Abstände und starken Kontrast.

Wie erstellen Sie ein einfaches Symbol für Ihre Wix-Website?

Verwenden Sie eine quadratische Leinwand und konzentrieren Sie sich auf ein erkennbares visuelles Element. Ein guter Anfangsprozess ist: Wählen Sie das Logo, Symbol oder die Initialen aus, entfernen Sie unnötige Details, platzieren Sie es auf einer quadratischen Leinwand, verwenden Sie starken Kontrast, exportieren Sie es und überprüfen Sie das Symbol in kleinen Größen.

Wie konvertiert man ein PNG in ein Favicon von Wix?

Wenn Sie bereits über ein PNG-Logo oder -Symbol verfügen, können Sie es mit einem Favicon-Konvertierungstool vorbereiten. PNGtoFavicon.com kann ein vorhandenes PNG in Favicon-Grafik umwandeln. Dies ist nützlich, wenn Sie bereits über ein passendes Markenimage verfügen und dieses in ein spezielles Favicon umwandeln müssen. Stellen Sie nach der Konvertierung sicher, dass die resultierende Datei weiterhin den Favicon-Anforderungen von Wix entspricht (ICO, PNG, JPG oder SVG; Nicht-SVG-Bilder müssen quadratische Abmessungen haben, die ein Vielfaches von 48 Pixeln sind).

Welche Größe sollte ein Wix-Favicon haben?

Die aktuelle Anforderung von Wix besteht darin, dass ein Favicon ein Vielfaches von 48 Pixeln im Quadrat sein sollte, es sei denn, Sie verwenden eine SVG-Datei. Beispiele hierfür sind 48 × 48 und 96 × 96 Pixel.

Der wichtige Unterschied besteht zwischen dem hochgeladenen Bild und der Größe, in der ein Favicon angezeigt wird. Ein Browser zeigt das Favicon möglicherweise in einer viel kleineren Größe als das Originalbild an. Wix gibt außerdem an, dass Google die Favicons für Suchergebnisse auf 16 × 16 Pixel neu skaliert. Daher kann ein technisch gültiges Favicon immer noch ein schlechtes Favicon sein, wenn sein Text oder seine Grafiken zu detailliert sind.

Wie überprüfen Sie, ob Ihr Wix Favicon funktioniert?

Überprüfen Sie nach dem Hochladen des Favicons die Live-Website, anstatt davon auszugehen, dass der Upload erfolgreich war, nur weil das Bild in den Wix-Einstellungen angezeigt wird.

  • Überprüfen Sie die Registerkarte „Browser“: Öffnen Sie Ihre veröffentlichte Website. Das Favicon sollte neben dem Website- oder Seitennamen im Browser-Tab erscheinen.
  • Überprüfen Sie Ihre Lesezeichen: Setzen Sie ein Lesezeichen für die Website und überprüfen Sie den Lesezeicheneintrag. Favicons werden häufig in Lesezeichenschnittstellen verwendet.
  • Testen Sie die Live-Website: Stellen Sie sicher, dass Sie die veröffentlichte Domain überprüfen, nicht nur den Editor oder das Dashboard.
  • Testen Sie in einem privaten oder Inkognito-Fenster: Öffnen Sie ein privates oder Inkognito-Fenster und besuchen Sie die Website. Dadurch kann festgestellt werden, ob Ihr normaler Browser ein älteres zwischengespeichertes Favicon anzeigt.
  • Testen Sie einen anderen Browser: Öffnen Sie dieselbe Website in einem anderen Browser. Wenn das neue Favicon in einem Browser erscheint und in einem anderen nicht, ist Browser-Caching eine wahrscheinliche Erklärung.

Warum wird mein Favicon von Wix nicht angezeigt?

Mehrere Probleme können dazu führen, dass das Favicon fehlt.

Sie verfügen nicht über den erforderlichen Wix-Plan

Problem: Wix erfordert einen Premium-Plan und eine verbundene Domain für ein benutzerdefiniertes Favicon.
Fix: Überprüfen Sie Ihren Plan und stellen Sie sicher, dass Ihre benutzerdefinierte Domain mit der Site verbunden ist.

Ihre Website wurde nicht veröffentlicht

Problem: Wix gibt an, dass die Website veröffentlicht werden muss, bevor ein Favicon hinzugefügt werden kann.
Fix: Veröffentlichen Sie die Website und kehren Sie dann zu den Favicon-Einstellungen zurück.

Du hast die falsche Website von Wix bearbeitet

Problem: Ihr Konto verwaltet mehrere Websites und Sie haben das Favicon einer anderen Website geändert.
Fix: Überprüfen Sie vor der Bearbeitung den Site-Namen und die verbundene Domäne.

Sie haben ein ungeeignetes Bild hochgeladen

Problem: Das Bild entspricht nicht den erforderlichen Abmessungen oder verwendet ein Format, das Wix nicht unterstützt.
Fix: Verwenden Sie ICO, PNG, JPG oder SVG und stellen Sie sicher, dass ein Nicht-SVG-Favicon quadratische Abmessungen verwendet, die ein Vielfaches von 48 Pixeln sind.

Ihr Browser hat das alte Favicon zwischengespeichert

Problem: Das alte Favicon bleibt sichtbar, nachdem Sie es erfolgreich geändert haben.
Fix: Testen Sie die Website in einem privaten Fenster oder einem anderen Browser. Löschen Sie bei Bedarf zwischengespeicherte Browserdaten.

Sie testen den Editor anstelle der Live-Website

Problem: Das Favicon erscheint beim Arbeiten in Wix falsch.
Fix: Öffnen Sie die veröffentlichte Domain und überprüfen Sie dort die Browser-Registerkarte.

Google hat das Favicon in der Suche nicht aktualisiert

Problem: Ein Favicon, das in der Google-Suche erscheint, ist unabhängig davon, ob das Favicon bei Wix korrekt konfiguriert ist. Wix gibt an, dass die Indexierung von Google kontrolliert wird und dass Wix nicht garantieren kann, wann Google das Favicon anzeigt.
Fix: Bestätigen Sie zunächst, dass das Favicon auf der Live-Website funktioniert. Behandeln Sie die Anzeige in der Google-Suche als separaten Prozess.

Wie repariert man ein Wix-Favicon, das nicht aktualisiert wird?

Gehen Sie die Prüfungen in dieser Reihenfolge durch:

  1. Bestätigen Sie, dass Sie über einen Premium-Plan verfügen und Ihre Domain verbunden ist.
  2. Bestätigen Sie, dass die Website veröffentlicht ist.
  3. Öffne die richtige Wix-Site in deinem Dashboard.
  4. Gehe zu Einstellungen → Website-Einstellungen → Favicon.
  5. Bestätigen Sie, dass das richtige Bild ausgewählt ist, und klicken Sie Speichern.
  6. Öffnen Sie die veröffentlichte Domäne und testen Sie sie in einem privaten/Inkognito-Fenster oder einem anderen Browser.
  7. Leeren Sie den Browser-Cache, wenn das vorherige Symbol weiterhin angezeigt wird.

Wenn das Problem nur die Google-Suche betrifft, ermöglichen Sie den separaten Crawling- und Indexierungsprozess von Google. Diese Reihenfolge trennt Wix-Konfigurationsprobleme vom Browser-Caching und Suchmaschinenverhalten.

Wie ändert oder ersetzt man ein Wix-Favicon?

Beim Ersetzen eines vorhandenen Favicons wird derselbe Einstellungsbereich verwendet.

  • Öffne das Dashboard deiner Wix-Website und klicke Einstellungen.
  • Offen Website-Einstellungen.
  • Suchen Sie den Favicon-Bereich und klicken Sie auf die Option Bild hochladen/ersetzen.
  • Wählen Sie Ihr neues Favicon aus und speichern Sie die Änderung.
  • Veröffentlichen Sie die Site bei Bedarf, öffnen Sie dann die Live-Site und überprüfen Sie sie.

Die aktuelle Dokumentation zu den Website-Einstellungen von Wix bestätigt, dass das Favicon von diesem Bereich aus hochgeladen oder ersetzt werden kann. Für Benutzer des Harmony Editors besteht die alternative Möglichkeit darin, das Fenster „Site-Übersicht“ zu öffnen und auf „Favicon hinzufügen“ zu klicken.

Wie entferne ich ein Wix-Favicon?

Der Entfernungsprozess hängt von der aktuellen Benutzeroberfläche von Wix und davon ab, wie das Favicon der Website verwaltet wird.

Öffnen Sie die Favicon-Einstellungen der Site und suchen Sie nach der verfügbaren Option zum Entfernen, Ersetzen oder Zurücksetzen des aktuellen Favicons. Gehen Sie nicht davon aus, dass jede Benutzeroberfläche von Wix über eine Schaltfläche zum Entfernen mit demselben Namen verfügt.

Es gibt auch einen wichtigen Unterschied zwischen dem Entfernen eines benutzerdefinierten Favicons und dem Entfernen des Wix-Brandings. Wix gibt an, dass kostenlose Websites das Wix-Favicon verwenden, während für ein benutzerdefiniertes Favicon der entsprechende Premium-Plan und die verbundene Domain erforderlich sind.

Können Sie ein Favicon von Wix mit benutzerdefiniertem Code hinzufügen?

Normalerweise ist kein benutzerdefinierter Code erforderlich. Wix bietet über die Website-Einstellungen eine native Favicon-Einstellung und der neuere Harmony Editor bietet eine direkte Steuerung zum Hinzufügen von Favicons.

Wann sollten Sie die integrierte Favicon-Einstellung von Wix verwenden?

Verwenden Sie die integrierte Einstellung von Wix, wann immer sie verfügbar ist. Es ist einfacher zu verwalten und vermeidet unnötige Änderungen an der Implementierung der Site.

Wann könnte benutzerdefinierter Code erforderlich sein?

Benutzerdefinierter Code ist im Allgemeinen nur für ungewöhnliche oder stark angepasste Implementierungen relevant. Ändern Sie den Code Ihrer Website nicht, nur weil in einem Tutorial, das für eine ältere Benutzeroberfläche von Wix geschrieben wurde, eine codebasierte Favicon-Methode gezeigt wird.

Können Sie Ihr Logo als Wix-Favicon verwenden?

Ja. Wix weist ausdrücklich darauf hin, dass die meisten Unternehmen ihr eigenes Logo für das Favicon verwenden. Allerdings ist das vollständige Logo möglicherweise nicht immer die beste Wahl.

Sollten Sie das vollständige Logo verwenden?

Verwenden Sie das vollständige Logo nur, wenn es in Favicon-Größe noch erkennbar ist. Eine horizontale Wortmarke mit mehreren Wörtern kann zu klein zum Lesen werden.

Wann sollten Sie stattdessen ein Symbol oder Initialen verwenden?

Verwenden Sie den erkennbarsten Teil Ihrer Marke, wenn das vollständige Logo zu viele Details enthält. Ein Symbol, ein Monogramm oder ein oder zwei Initialen können ein stärkeres Favicon ergeben.

Häufige Favicon-Fehler von Wix, die Sie vermeiden sollten

  • Verwendung falscher Abmessungen: Verwenden Sie für Nicht-SVG-Favicons quadratische Abmessungen, die ein Vielfaches von 48 Pixeln sind.
  • Verwendung eines unnötig komplizierten Logos: Reduzieren Sie die Anzahl der Elemente, damit das Symbol erkennbar bleibt.
  • Verwendung von kleinem Text: Text, der in einem großen Logo lesbar ist, kann in einem Favicon unsichtbar werden.
  • Verwendung von schlechtem Kontrast: Sorgen Sie dafür, dass sich das Symbol vom Hintergrund abhebt.
  • Hochladen minderwertiger Kunstwerke: Beginnen Sie mit einem sauberen Quellbild.
  • Vergessen Sie die Premium-Plan-Anforderung: Für ein benutzerdefiniertes Favicon sind ein Premium-Plan und eine verbundene Domain erforderlich.
  • Vergessen zu veröffentlichen: Wix verlangt, dass die Website veröffentlicht wird, bevor ein Favicon hinzugefügt wird.
  • Nur einen Browser prüfen: Ein zwischengespeichertes Favicon kann ein erfolgreiches Update wie einen fehlgeschlagenen Upload aussehen lassen.
  • Wir erwarten ein sofortiges Update von Google: Google kontrolliert, wann Favoriten gecrawlt und angezeigt werden. Wix kann nicht garantieren, wann das passieren wird.
  • Verwechslung des Favicons mit dem Browsertitel: Wenn Sie Ihr Favicon ändern, ändert sich das kleine Symbol. Der als Seitentitel angezeigte Text wird nicht automatisch geändert.

Wix Favicon-FAQs

Kann ich Wix kostenlos ein Favicon hinzufügen?

Nein. Wix gibt an, dass das Hinzufügen eines benutzerdefinierten Favicons einen Premium-Plan und eine verbundene Domain erfordert. Kostenlose Websites von Wix verwenden das Standard-Favicon von Wix.

Welche Größe sollte ein Wix-Favicon haben?

Bei Nicht-SVG-Dateien muss das Favicon ein Vielfaches von 48 Pixeln im Quadrat sein, beispielsweise 48 × 48 oder 96 × 96 Pixel. SVG-Dateien sind von dieser Anforderung an die Pixelgröße ausgenommen.

Welches Dateiformat verwendet Wix für Favicons?

Wix unterstützt geeignete Favicon-Formate, darunter ICO, PNG, JPG und SVG.

Kann ich ein PNG als Favicon von Wix verwenden?

Ja. PNG wird unterstützt, einschließlich PNG-Bildern mit transparentem Hintergrund.

Kann ich eine SVG-Datei als Wix-Favicon verwenden?

Ja. Wix listet SVG als unterstütztes Favicon-Format auf und SVG ist von der Anforderung eines Vielfachen von 48 Pixeln ausgenommen.

Kann ich mein Logo als Favicon von Wix verwenden?

Ja. Ein Logo ist eine gängige Wahl, aber vereinfachen Sie es bei Bedarf, damit es auch bei kleiner Größe erkennbar bleibt. Wix weist darauf hin, dass die meisten Unternehmen ihr eigenes Logo als Favicon verwenden.

Warum wird mein Favicon von Wix nicht angezeigt?

Bestätigen Sie, dass Ihre Website über den erforderlichen Premium-Plan und die verbundene Domain verfügt, dass die Website veröffentlicht ist und dass Sie das Favicon auf die richtige Website von Wix hochgeladen haben. Testen Sie dann die Live-Site in einem privaten Fenster oder einem anderen Browser, um Caching auszuschließen.

Warum wird das Wix-Logo immer noch als mein Favicon angezeigt?

Kostenlose Websites von Wix verwenden das Wix-Favicon. Für ein benutzerdefiniertes Favicon sind ein Premium-Plan und eine verbundene Domain erforderlich.

Wie ändere ich mein Favicon bei Wix?

Gehen Sie zu Einstellungen → Website-Einstellungen → Favicon, laden Sie das Bild hoch oder ersetzen Sie es und speichern Sie die Änderung. Im neueren Harmony-Editor können Sie auch das Fenster „Site-Übersicht“ öffnen und auf „Favicon hinzufügen“ klicken.

Wie entferne ich ein Wix-Favicon?

Öffnen Sie die Favicon-Steuerelemente in den Einstellungen Ihrer Wix-Site und verwenden Sie die verfügbare Option zum Entfernen, Ersetzen oder Zurücksetzen. Die genaue Steuerung kann je nach Wix-Schnittstelle variieren.

Wie lange dauert die Aktualisierung eines Wix-Favicons?

Es gibt keine universelle Anzeigezeit. Ihre Wix-Einstellungen können aktualisiert werden, während Ihr Browser weiterhin ein zwischengespeichertes Favicon anzeigt. Die Google-Suche verfügt über einen separaten Crawling- und Indexierungsprozess und Wix übernimmt keine Garantie dafür, wann Google das aktualisierte Favicon anzeigt.

Warum wird mein Favicon von Wix nicht in der Google-Suche angezeigt?

Wix gibt an, dass Google entscheidet, wann ein Favicon indiziert wird und ob es in den Suchergebnissen angezeigt wird. Ein korrekt funktionierendes Favicon in Ihrem Browser garantiert nicht, dass Google es sofort neben Ihrem Sucheintrag anzeigt.

Muss ich meine Website bei Wix veröffentlichen, bevor ich ein Favicon hinzufüge?

Ja. In der Favicon-Dokumentation von Wix heißt es, dass die Website veröffentlicht werden muss, bevor Sie ein Favicon hinzufügen können.

Benötige ich einen Premium-Plan von Wix, um ein Favicon hinzuzufügen?

Ja. Wix erfordert einen Premium-Plan und eine verbundene Domain für ein benutzerdefiniertes Favicon.

So erstellen Sie ein Favicon, bevor Sie es auf Wix hochladen

Verwenden Sie diesen Workflow, wenn Sie noch kein Favicon haben:

  1. Beginnen Sie mit Ihrem Logo, Symbol oder Ihren Initialen. Behalten Sie das ursprüngliche Logo und die Markenidentität bei.
  2. Vereinfachen Sie das Bildmaterial für eine kleine Darstellung.
  3. Erstellen Sie ein quadratisches Bild (verwenden Sie für Nicht-SVG-Dateien Abmessungen, die ein Vielfaches von 48 Pixeln sind).
  4. Exportieren Sie das Bild als PNG, JPG, ICO oder SVG.
  5. Überprüfen Sie das Favicon in kleiner Größe.
  6. Verwenden Sie einen Favicon-Konverter wie z PNGtoFavicon.com wenn Sie bereits ein PNG haben, das konvertiert werden muss.
  7. Laden Sie das fertige Favicon auf Wix hoch.
  8. Speichern und veröffentlichen Sie die Site.
  9. Überprüfen Sie die Live-Website in einem Browser-Tab.

Abschluss

Um ein Favicon auf Wix anzupassen, bereiten Sie ein einfaches quadratisches Symbol vor, öffnen Sie dann Einstellungen → Website-Einstellungen → Favicon und laden Sie das Bild hoch. Speichern Sie die Änderung und überprüfen Sie das Ergebnis auf der veröffentlichten Website. Wenn Sie den neueren Wix Harmony Editor verwenden, können Sie auf dieselbe Aufgabe direkt über Site-Übersicht → Favicon hinzufügen zugreifen. Die beiden wichtigsten Anforderungen sind der Premium-Plan von Wix mit einer verbundenen Domain und einer veröffentlichten Website. Wenn das Favicon nach dem Speichern immer noch nicht erscheint, testen Sie die Live-Site in einem privaten Fenster oder einem anderen Browser. Die Sichtbarkeit in der Google-Suche ist ein separater Prozess, der von Google gesteuert wird.
